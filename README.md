# 🤖 Personal Python Chatbot

A simple console-based chatbot built using Python.  
This chatbot can chat with users, tell jokes, show date & time, motivate users, and answer basic programming-related questions.

---

# 📌 Features

✅ Greetings Response  
✅ Time, Date, and Day Information  
✅ Motivation Messages  
✅ Funny Programming Jokes  
✅ Study Tips  
✅ Python & Java Information  
✅ User-Friendly Chat Interface  
✅ Exit Command Support  

---

# 🛠️ Technologies Used

- Python 3
- datetime module
- random module

# ▶️ How to Run the Project

## Step 1: Install Python

Download and install Python from:

https://www.python.org/downloads/

While installing Python, make sure to check:

✅ Add Python to PATH

---

## Step 2: Save the Program

Save your chatbot code in a file named:

chatbot.py

---

## Step 3: Open Terminal / Command Prompt

Navigate to the project folder.

Example:

cd Desktop/project-folder

---

## Step 4: Run the Program

Use the following command:

python chatbot.py

OR

python3 chatbot.py
